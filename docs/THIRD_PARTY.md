# Third-party code, dependencies and art

Everything in this repository that is not Crown Park Computing's own work.
Licence strings for the Rust crates are taken from `cargo metadata`, not from
memory.

**As of 2026-11-21 there are no unresolved items.** Every third-party asset
that was here has been removed; see "Resolved" below for what each one was.

## Format descriptions used, without using their source

- **libchdr** (BSD-3-Clause) — the CHD container format was read from libchdr
  as a format description. The reader in `app/src/chd/` is new Rust code and
  links no part of libchdr.
- **CR-560B device documentation** (BSD-3-Clause, as published by MAME) — CD
  device command and reply shapes only. No MAME source is compiled here.

Both are documentation-use, and both licences are permissive and compatible
with this project's MIT licence. BSD-3-Clause attribution is given by this
file.

## Resolved on 2026-11-21

These were removed from the working tree and replaced with Crown Park
Computing's own generated artwork. They remain in this repository's **git
history**, which is why the tree must be published as a fresh initial commit
rather than pushed with its history; see `docs/PROVENANCE.md`.

| Removed | Was | Replaced by |
|---|---|---|
| `gow2.jpg`, `gow2-dvd.jpg` | Retail cover and disc art for a commercial game, used as the sample case texture | `case-wrap-sample.jpg`, `disc-sample.jpg` |
| `boot-logo-real.png` | Described in commit `8587c90` as the real BIOS boot logo; The 3DO Company's artwork | Nothing — the file was referenced by no code and is simply gone. A boot logo must come from a BIOS the *user* supplies at runtime, never from a file we ship. |
| `3do-mark.png` | The 3DO wordmark, which was `include_bytes!`'d into the shipping binary by `boot_logo.rs` and `case_art.rs` | `cpc-mark.png` |
| `retro_recomp_logo.png` | Origin never recorded | `fz1-poster.jpg` (ours) |
| `dvd-case/source/case.fbx` | Third-party DVD case model, origin never recorded | `case.glb`, built from nothing by `docs/make-case-model.py` |
| `Fingerprints002_2K_*.jpg` (4 files, ~12 MB) | Third-party surface maps for a clear-sleeve overlay that is not modelled; referenced by no code | Removed, nothing needed |

All replacement art is produced by `docs/make-placeholder-art.py`, so its
provenance is that script and this repository.

## Unresolved items

**None.** Every third-party asset has been removed and replaced with artwork
and geometry generated by scripts in this repository
(`docs/make-case-model.py`, `docs/make-placeholder-art.py`). This tree carries
no art whose licence is unknown.

Normal-use artwork is not shipped at all: covers, spines and disc labels come
from the person's own RetroMedia library at runtime. See
[CASE-ARTWORK.md](CASE-ARTWORK.md).
